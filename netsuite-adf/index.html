What it is

A FastAPI microservice built for ADF Web Activity: you POST a SuiteQL query and destination blob name; the service authenticates with NetSuite Token-Based Authentication (OAuth 1.0a TBA), paginates results until hasMore is false, and uploads JSON to Azure Blob Storage.

Why teams buy this

  • SuiteAnalytics Connect and managed sync tools often run $1k–$10k+/year
  • Custom builds for the same path commonly land in the $8k–$25k services range
  • This kit is a readable, deployable starting point (Docker / Container Apps) with MOCK_MODE so you can demo without prod credentials
Flow: ADF schedule → Web Activity → POST /v1/extract → NetSuite SuiteQL pages → Azure Blob JSON → ADF continues to silver/gold.

NetSuite TBA tokens (or mock mode), Azure Storage connection string (or mock mode), Python 3.10+ or Docker.
