Stamp every trip · Version 1.3.1 · about 1.1 MB · Android 7 or newer
Download for Android

Your family's maps and trips stay on your own phone. No account needed.

  1. Tap Download, then open the file when it finishes (check your notifications or the Downloads app).
  2. Allow the install. If your phone says it can't install unknown apps, tap Settings, turn on Allow from this source for your browser, then go back.
  3. Tap Install, then Open. If Play Protect asks about the app, tap More details, then Install anyway.
Already have the app?

Install this over it. Your maps and trips stay put; it now shows up on your phone as Famstamp (it used to say Travel Log or Famstamp).

On an iPhone or iPad?

This file only works on Android. Open the app in Safari, tap the Share button, then Add to Home Screen.

Already using it in Chrome on this phone?

The app usually opens with the same maps and trips. To be safe, open it in Chrome first, tap Back up and save the file. If anything is missing in the app, use Back up, then Restore.
